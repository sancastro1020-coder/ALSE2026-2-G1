# Práctica 1 - Git

## Descripción

En esta práctica se realizaron diferentes operaciones básicas utilizando Git y Linux/Bash.

## Actividades realizadas

- Clonación del repositorio.
- Cambio a la rama `dev`.
- Creación de la rama `practica1-git`.
- Creación de la carpeta `practica1`.
- Inclusión de archivos correspondientes a la práctica de Linux/Bash.
- Consulta de archivos `.txt` mediante `find`.
- Obtención de permisos y detalles de archivos mediante `ls -l`.
- Conteo de líneas de un archivo CSV mediante `wc -l`.
- Búsqueda de la palabra `female` mediante `grep`.

## Resultados

- Archivos `.txt` encontrados: 20.
- Líneas del archivo CSV: 2946.
- Apariciones de la palabra `female`: 51.

## Rama utilizada

`practica1-git`
## Comandos principales utilizados

- `find` para buscar archivos.
- `ls -l` para consultar permisos y detalles.
- `wc -l` para contar líneas.
- `grep` para buscar palabras dentro de archivos.
